In this project uses the LSTM model architecture to predict energy consumption fairly accurately. Although this project is based on the data and code produced by Soumil Shah as shown in https://www.youtube.com/watch?v=rAYFuFNOCic&list=PL6EROQQjZD8ncsbvkoS2NuEN1DHalhyfm, I have fixed some problems. In the original code, there was a convergence between training and testing dataset. In this version not only has this issue has been resolved, but I have also included a visual and quantitative representation of the error of the model's output which previously was absent.
