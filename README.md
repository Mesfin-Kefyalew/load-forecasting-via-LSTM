This project uses the LSTM model architecture to predict energy consumption with reasonable accuracy. Although it builds on the data and code provided by Soumil Shah ([as shown in this YouTube video](https://www.youtube.com/watch?v=rAYFuFNOCic&list=PL6EROQQjZD8ncsbvkoS2NuEN1DHalhyfm)), I’ve addressed several issues present in the original version. Specifically, the original code had a convergence between the training and testing datasets. In this version, not only has that issue been resolved, but I’ve also added both visual and quantitative representations of the model’s error—something that was previously missing.
